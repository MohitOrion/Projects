# Event Horizon Checkbox 🕳️

An interactive web experiment where a single click triggers an irreversible gravitational singularity that consumes the entire user interface.

## ✨ Features

- **Dynamic Canvas Rendering**: High-performance `<canvas>` based animations for stars, particles, and the black hole itself.
- **Gravitational Lensing**: Background stars stretch, warp, and spiral inward realistically.
- **Accretion Disk Mechanics**: A tilted, spinning ring of hot plasma orbits the singularity, accelerating as consumption progresses.
- **UI Spaghettification**: The HTML DOM elements stretch, blur, and spiral into the center of the black hole upon activation.
- **Multi-Stage Cinematic Experience**:
  - **Idle**: A calm universe with twinkling stars.
  - **Hover**: An ominous, glitching "Point of No Return" warning with CRT scanlines and red alert lighting.
  - **Consumption**: The 6-second un-stoppable collapse sequence with screen shake.
  - **The Void**: A post-consumption eerie calmness with theoretical physics coordinates (r=0, t=∞).

## 🚀 How to Run

Since the project uses pure HTML, CSS, and JavaScript with no build tools required, you can run it using any local development server.

If you have Python installed:
```bash
python -m http.server 3000
```

If you have Node.js/npx installed:
```bash
npx serve . -l 3000
```

Then open `http://localhost:3000` in your web browser.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **Vanilla CSS3**: Advanced animations, glassmorphism, flexbox, custom gradients, and CSS variables.
- **Vanilla JavaScript (ES6+)**: Custom 2D physics engine, `requestAnimationFrame` loop, canvas rendering, and DOM manipulation.

## ⚠️ Warning

*Once activated, the singularity cannot be stopped. Everything will be consumed. There is no coming back.*
